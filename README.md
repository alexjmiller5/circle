# Circle / Nudge App

A check-in app to help you stay in touch with the people who matter most.

## About

Circle (working title: Nudge) is an iOS app that helps you maintain meaningful relationships by tracking communication and suggesting when to reach out.

- Written in Swift
- Uses SQLite for call history
- Authentication and sync through iCloud
